# 魔改内容

1.增加豆瓣评分及显示个数（需要搭配魔改版 tmdb 助手） https://github.com/wabisabi926/plugin.video.themoviedb.helper/tree/douban ；

2.增加海报墙标题；

3.优化海报墙的播放状态指示器；

4.OSD 播放列表顺序优化及聚焦到当前播放剧集；
